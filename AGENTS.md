# Regras do projeto

Este projeto é um trabalho acadêmico em React Native com Expo.

## Git

- Trabalhar sempre na branch `develop`.
- Nunca alterar ou enviar commits diretamente para `main`.
- O agente pode criar e editar arquivos.
- O agente pode instalar dependências necessárias.
- O agente pode executar testes e verificações.
- O agente pode fazer commits.
- O agente pode fazer push para `develop`.
- Não criar Pull Request nem fazer merge para `main` sem autorização.
- Antes de cada commit, verificar se o projeto continua funcionando.
- Usar mensagens de commit claras e objetivas.

## Objetivo

Implementar o aplicativo exigido pela disciplina Mobile Development.

Priorizar:
- funcionamento;
- organização;
- simplicidade;
- aderência aos requisitos;
- facilidade para demonstrar o projeto na entrega.

Não adicionar funcionalidades fora do escopo sem necessidade.

## Requisitos principais

- React Native com Expo.
- Axios.
- Redux Toolkit.
- Tela de login com validação.
- Armazenamento temporário dos dados do usuário.
- Tela de listagem de produtos.
- Tabs masculino/feminino.
- Consumo da DummyJSON API.
- Tela de detalhes do produto.
- Exibir nome, imagem, descrição, preço e desconto.
- Logout funcional.
- O projeto deve rodar com `npx expo start`.
